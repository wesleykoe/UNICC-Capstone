Update the application to support a clean "no evaluation yet" initial state.

GOAL:
When the user first opens the app, Dashboard, Expert Panel, and Council Decision should NOT show any results.

-----------------------------------
1. GLOBAL STATE
-----------------------------------
Introduce a global state:

- hasRunEvaluation (boolean)
- currentEvaluation (object or null)

Initial state:
- hasRunEvaluation = false
- currentEvaluation = null

-----------------------------------
2. DASHBOARD (OVERVIEW PAGE)
-----------------------------------
If hasRunEvaluation = false:
- Hide all decision cards
- Show an empty state:

Title:
"No evaluation results yet"

Subtitle:
"Run a council review to generate a safety decision"

If hasRunEvaluation = true:
- Show the current Overview UI

-----------------------------------
3. EXPERT PANEL
-----------------------------------
If hasRunEvaluation = false:
- Do NOT render expert cards
- Show empty state:

"No expert assessments available"
"Experts will appear after running an evaluation"

If hasRunEvaluation = true:
- Show expert cards normally

-----------------------------------
4. COUNCIL DECISION PAGE
-----------------------------------
If hasRunEvaluation = false:
- Do NOT show any decision
- Show empty state:

"No council decision available"
"Run an evaluation to generate a decision"

If hasRunEvaluation = true:
- Show the council decision UI

-----------------------------------
5. RUN FLOW
-----------------------------------
When user clicks:
- Run Council Review
- OR second click of Test Demo

Then:
- set hasRunEvaluation = true
- set currentEvaluation = mock or real result

-----------------------------------
6. CLEAR / RESET
-----------------------------------
When Clear is clicked:
- set hasRunEvaluation = false
- set currentEvaluation = null

-----------------------------------
7. REPORTS PAGE
-----------------------------------
Keep Reports and Recent Evaluations always visible (mock or stored data)

-----------------------------------
GOAL RESULT:
The app should feel like:
- Empty system before first run
- Fully populated system after evaluation
- Resettable state for repeated demos
