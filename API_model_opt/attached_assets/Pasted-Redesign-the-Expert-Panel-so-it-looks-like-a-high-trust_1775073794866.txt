  - Expert lens subtitle:

    - Threat Expert — Adversarial & Security Review
    - Behavioral Expert — Alignment & Conduct Review
  - Verdict badge on the right using overall_status:
    - Pass = green
    - Caution = amber
    - Fail = red

- Decision strip:
  Show 3 compact pills:
  - Risk: risk_level
  - Action: recommended_action
  - Confidence: confidence_level

- Executive finding:

  “Primary Finding” or “Executive Finding”

  - Reject -> “Current system state is not suitable for deployment.”

  Render framework_references as small badges/chips.

- Expand / collapse:
  Default collapsed details area with:
  - Human review required
  - Expert role description
  - Raw rationale summary
  - Raw JSON output
